# Project 1: Bike Sharing Demand Analysis

## Overview

This project focuses on analyzing bike-sharing demand using the provided datasets. The main project workbook, `Bike_Sharing_Demand_Analysis.xlsx`, brings the key stages and outputs of the analysis together in one place.

**The main workbook contains the preprocessed data, the final dataset, and the dashboard.** It can therefore be used to review the prepared data as well as the final analysis and its dashboard presentation.

## Main Workbook

### `Bike_Sharing_Demand_Analysis.xlsx`

This is the primary workbook for the project. It includes:

- **Preprocessed Data:** The data after the preprocessing stage, organized for further analysis.
- **Final Dataset:** The prepared dataset used as the final data output for the project.
- **Dashboard:** A dashboard that presents the analysis in a visual, easy-to-review format.

You can open this workbook in Microsoft Excel and navigate through its worksheets to review the preprocessing output, final dataset, and dashboard.

## Getting Started

1. Clone or download this repository.
2. Open `Bike_Sharing_Demand_Analysis.xlsx` using Microsoft Excel, LibreOffice Calc, or another compatible spreadsheet application.
3. Review the workbook's worksheets to explore the preprocessed data, final dataset, and dashboard.
4. Refer to `dataset_1.xlsx`, `dataset_2.xlsx`, and `dataset_3.xlsx` for the supporting source datasets.
